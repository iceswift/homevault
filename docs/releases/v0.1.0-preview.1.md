# HomeVault v0.1.0-preview.1

First experimental Linux preview. This is not a stable production release or a
complete server/disk-image backup product. Start with generated data and verify a
restore before configuring real application data.

## Included

- Go CLI/TUI for encrypted Restic backup, snapshot listing, repository checks and
  explicit restore into a new destination.
- Getting-started help, backup confirmation and scrollable job history/details.
- Google Drive transport through separately installed rclone; manual desktop
  OAuth client setup and local credential wizard.
- Experimental database preparation, coordinated capture, recovery kits,
  retention review, Discord alerts and systemd workflow templates.
- Local Quick Start and public recovery/validation documentation in the archive.

## Downloads and compatibility

| Asset | Compatibility |
| --- | --- |
| `homevault_v0.1.0-preview.1_linux_amd64.tar.gz` | Ubuntu/Linux amd64 preview; extracted-package generated-data restore tested in CI |
| `homevault_v0.1.0-preview.1_linux_arm64.tar.gz` | Cross-built and archive/ELF checked; runtime unverified |
| `SHA256SUMS` | SHA-256 hashes for both archives |

No Windows/macOS deployment package is supplied. Restic and rclone are not bundled.
Restic 0.19.1 is used in generated-data CI; rclone 1.75.2 was used in the operator
cloud drill. Python 3.11+ is needed for this sample walkthrough/optional workflows;
age 1.3.2 is the tested optional recovery-kit tool. These are tested versions,
not a promise of compatibility with every older or newer version.

See [installation and verification](https://github.com/iceswift/homevault/blob/v0.1.0-preview.1/docs/RELEASING.md).
Every archive includes `RELEASE.json` with its exact source commit, version,
architecture, build toolchain and external-tool notes. Checksums detect corruption;
they are not signatures or independent publisher authentication.

## Verification and limits

Release CI runs Go race tests/vet, generated-data Restic recovery fixtures,
package-checker negative tests, checksum/metadata/ELF validation and an actual
backup/check/restore using the extracted amd64 binary and bundled demo script.
ARM64 is not executed. Review the matching tag's GitHub Actions run.

Separate operator evidence covers selected applications restored from Drive into
an isolated Ubuntu VM on the original physical server. It does not prove complete
host recovery, physical disk-loss recovery or compatibility with arbitrary apps.

Schedules, cloud credentials and retention are never activated by downloading or
opening this release. No automatic production restore/cutover is included.
Repository-key custody remains the operator's responsibility.
