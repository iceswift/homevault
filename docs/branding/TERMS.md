# HomeVault Personal — Usage and limitations

Updated: 24 October 2026. Official information site: https://homevault.suwiwat.com/.

HomeVault Personal is experimental self-hosted software. The operator selects the source data, storage destination and credentials, and is responsible for having authority to back up that data and for complying with the storage provider's terms.

Keep independent backups and recovery passwords, and test restoration before depending on a backup. Successful file upload or repository metadata checks do not establish that a database or application can be recovered. The current release does not automatically prepare running databases or enable a production backup schedule.

Source code is offered under the MIT license included with the project. Third-party components such as Restic, rclone and Go dependencies retain their own licenses. No paid hosting or availability commitment is offered through this personal installation.
